# Stonkfly: установка и стрим

## Установка

**Windows:** скачай [Stonkfly-Setup.bat](https://raw.githubusercontent.com/MondayDecember/stonkfly/main/Stonkfly-Setup.bat) и запусти двойным кликом. Если Ubuntu для WSL нет, он её поставит, потом запусти его ещё раз. Остальное (Python, коннектом мухи, часы, ярлык на рабочем столе) он сделает сам.

**Уже есть Ubuntu:** одна команда:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/MondayDecember/stonkfly/main/install.sh)
```

## Запуск

Двойной клик по **Stonkfly.bat** на рабочем столе: муха запустится, страница откроется в браузере. Рядом появится свёрнутое окно «Stonkfly: логи». Его не закрывай, иначе Windows может усыпить Ubuntu вместе с мухой.

## Команда stonkfly

| команда | что делает |
| --- | --- |
| `stonkfly open` | запустить и открыть страницу (`open clean` для чистого вида, `open full` для вида с мозгом) |
| `stonkfly status` | что сейчас делает муха |
| `stonkfly logs` | живые логи (выйти: Ctrl+B, потом D) |
| `stonkfly stop` / `restart` | остановить / перезапустить |
| `stonkfly season` | закончить сезон и начать новый с $100 |
| `stonkfly update` | скачать обновления с GitHub |

После временных остановок (часы, сеть, спред) муха перезапускается сама. Если она проиграет $20 лимита, на экране появится GAME OVER. Новый сезон: `stonkfly season`.

## Адреса страниц

- `http://localhost:8080/stonkfly-3d.html`: 3D-сцена с управлением мышью.
- `http://localhost:8080/stonkfly-3d.html?stream=1`: режим трансляции (значок LIVE, всплывающие надписи о сделках). Камера свободная: ставишь её мышью, и она остаётся на месте.
- `...?stream=1&auto=1`: автокамера, сама переключает ракурсы.

### Локации

Муха может работать в четырёх местах. Переключение клавишей **L** или ссылкой:

| ссылка | локация |
| --- | --- |
| `?loc=room` | квартира с окном на город, день и ночь по солнцу над Томском |
| `?loc=floor` | торговый зал биржи 80-х: ЭЛТ-монитор, бегущая строка с настоящей ценой, часы мировых бирж, соседи-мухи; при исполненной сделке сыплются бумажки |
| `?loc=trash` | офис в мусорном ведре: стол из коробки от пиццы, картонный монитор на банке газировки; на «наказание» сверху падает бумажный комок |
| `?loc=brain` | внутри собственного мозга: вокруг настоящие нейроны мухи, на каждом тике вспыхивают связи между активными клетками |
| `?loc=mount` | проповедь на горе: муха на камне обращается к толпе мух на склоне, субтитры с «мушиной мудростью» зависят от её настоящих решений; на награду слушатели жужжат, на убыток понуро оглядываются |

Для каждой локации камера запоминается отдельно. Для OBS удобно завести по сцене на локацию, например `...?stream=1&loc=floor`.

### Камера

Левая кнопка мыши вращает, правая сдвигает, колесо приближает. Положение запоминается само. **C** копирует ссылку с этой камерой: вставь её в OBS, и ракурс не собьётся даже после очистки кэша. **R** сбрасывает камеру.

В OBS: правый клик по источнику → **Взаимодействовать**, в открывшемся окне ставишь камеру мышью, закрываешь окно.
- `http://localhost:8080/stonkfly-viewer.html`: простая панель с графиками.

Если `localhost` не открывается, используй адрес из `hostname -I`.

## Стрим на YouTube через OBS

1. YouTube Studio → **Создать → Начать трансляцию → Трансляция**. Скопируй **ключ трансляции**. В первый раз YouTube может подтверждать канал до 24 часов.
2. OBS → **Настройки → Трансляция**: сервис YouTube - RTMPS, вставь ключ (или «Подключить аккаунт»).
3. **Настройки → Вывод**: кодировщик NVIDIA NVENC H.264, битрейт 6000 Кбит/с. **Видео**: 1920×1080, 30 FPS.
4. **Источники → + → Браузер**:
   - URL: `http://localhost:8080/stonkfly-3d.html?stream=1`
   - Ширина 1920, высота 1080, FPS 30
   - галочку «Обновить браузер, когда сцена становится активной» поставить
5. Звука у страницы нет. Музыку можно добавить отдельным источником, например lo-fi без авторских претензий из фонотеки YouTube.
6. **Начать трансляцию**.

Компьютер не должен засыпать: Windows → Параметры → Система → Питание → «Переводить в спящий режим» → **Никогда**.

## Что на экране настоящее

Настоящие, из `runs/paper/events.jsonl`: цены BTC-USDC, решения BUY/SELL/HOLD (выход нейронов DNp20 и DNpe017), исполнение или вето, баланс, стимуляция дофаминовых нейронов, спайки, частоты L/R, изменённые синапсы.

Декорация: движения 3D-мухи, стакан заявок, пиксели растра (их густота при этом соответствует реальным счётчикам групп нейронов).

Торговля бумажная: виртуальные $100, реальные цены. Прибыльное обучение не доказано.

## Другие мухи

Рядом с торговой мухой работают ещё три, у каждой свой мозг (тот же коннектом MaleCNS). Торговую муху они не трогают. Каждая занимает одно ядро процессора и 1–2 ГБ памяти. Выбрать, какие запускать: `stonkfly apps "flappy oracle dreams"`, затем `stonkfly restart`.

### Flappy Fly

Мозг мухи играет во Flappy Bird: видит кадр игры, а взмах решает сама её память, выходные нейроны грибовидного тела MBON11 («за») против MBON07 («против»). Взмахов около 20% (столько нужно, чтобы держаться в воздухе), память решает, когда. После удара приходит сигнал ошибки по направлению: удар снизу — дофамин PAM11 («махать чаще» в похожих картинках), удар сверху — PPL101 («махать реже»). Это сезон 2; в сезоне 1 взмах решали DNp20, и проверка `stonkfly check` показала, что выученное до них не доходило. Проверить, учится ли муха: `stonkfly check` (что изменилось в памяти и машет ли муха чаще, когда птица низко). Страница: `http://IP:8080/flappy.html` (или `stonkfly flappy`). Там счёт, рекорд, «глазами мухи», нейроны и кривая обучения по попыткам. Если средний счёт со временем растёт, значит, муха учится.

В комнате в режиме игры к мухе заходят мама и папа и оставляют дверь открытой. Муха ставит игру на паузу, летит закрывать дверь и потом снимает паузу. Пауза настоящая: flappyfly.py останавливает игру и мозг (порт 8082, `/pause?s=15` и `/resume`, не дольше 30 с). Проверить визит сразу: добавь к адресу `&mom=fast` (или `&visit=dad`), отключить визиты: `&mom=0`.

### Муха выбирает цвет
Обучение, для которого грибовидное тело мухи и существует: как опыты с живыми дрозофилами (Т-лабиринт, выбор цвета). Урок: муха смотрит на цвет, и ей дают сахар (дофамин PAM11) или удар (PPL101). Экзамен: муха по очереди смотрит на синий и зелёный, выбирает её память (MBON11 «тянет» против MBON07), без всяких подсказок. Сначала 20 экзаменов без уроков (врождённый вкус), потом каждые 150 экзаменов сладкий цвет меняется местами с горьким: врождённая любовь к одному цвету не может следовать за переменой, а память может. Главная цифра — точность в среднем по обоим цветам, случайность 50%.

Смотреть: `http://localhost:8080/stonkfly-3d.html?stream=1&mode=colors` (или клавиша G). Цифры в терминале: `stonkfly colors`. Одна проба ~30 с счёта, около 100 экзаменов в час.

### Муха-оракул

Вопрос «да или нет» показывается мухе как картинка с текстом, ответ даёт DNp20. Спросить можно тремя способами:

- страница `http://IP:8081/` (удобно с телефона в той же сети);
- из Ubuntu: `stonkfly ask Биткоин вырастет завтра?`;
- из чата YouTube: сообщение `!муха вопрос`, если запустить оракула с `YT_VIDEO=<id трансляции>` и поставить `.venv/bin/pip install pytchat`.

Ответ на 45 секунд появляется табличкой на 3D-сцене (клавиша **O** прячет). Стоп-слова для вопросов из чата: файл `oracle_banned.txt`, по слову в строке.

### Сны мухи

Раз в час состояние мозга (какие отделы активны) и торговли (награды, наказания, цена BTC) превращается в описание сна, и ComfyUI рисует картинку. Она появляется в панели «Сон мухи» (клавиша **D**), а в квартире висит на стене.

Настройка ComfyUI, один раз:

1. Открой в ComfyUI свой рабочий процесс (Z-Image-Turbo). В узле положительной подсказки замени текст на `{DREAM}`.
2. Меню → Export (API) → сохрани как `~/stonkfly/dream_workflow.json`.
3. Настройки ComfyUI Desktop → Server-Config → Listen address: `0.0.0.0`. Если ComfyUI на другом компьютере, задай адрес: `echo 'export COMFY_URL=http://192.168.10.171:8000' >> ~/.bashrc`.
4. Проверка: `stonkfly dream`.
